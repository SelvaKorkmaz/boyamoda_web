# 🎨 Boyamoda – Duvar Boyası E-Ticaret Sitesi

**Boyamoda**, HTML, CSS ve JavaScript kullanılarak geliştirilmiş, kullanıcı dostu bir duvar boyası e-ticaret sitesidir.  
Kullanıcılar ürünleri keşfedebilir, sepete ekleyip çıkarabilir ve hızlıca alışveriş deneyimini yaşayabilir.  

## ✨ Öne Çıkan Özellikler
- Ürünleri kolayca listeleme ve görüntüleme  
- Sepete ürün ekleme ve çıkarma  
- Temiz ve modern kullanıcı arayüzü  
- Web geliştirme pratiği ve öğrenme amaçlı tasarlanmıştır  

> Bu proje, web geliştirme becerilerini artırmak ve temel e-ticaret işlevlerini öğrenmek isteyenler için ideal bir örnektir.
